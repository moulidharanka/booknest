# 📚 BookNest — Digital Library & Reader Platform

BookNest is a full-stack MERN application providing a dual-mode reading and library checkout experience.

---

## ✨ Features

- 🟢 **Read Free (Public Domain)**: Instant, unrestricted access to 109+ classic literary works from Project Gutenberg with authentic cover artwork and an in-browser distraction-free reader.
- 🔒 **Library Loans (Copyrighted Catalog)**: Digital 14-day checkout system for modern copyrighted titles with real-time available copy tracking and multi-chapter reading access.
- 👤 **User Accounts & Authentication**: Secure JWT authentication and bcrypt password hashing with user profiles and loan histories.
- 📋 **Loan Management**: Live countdowns, return actions, and loan history clearing.
- 📱 **Responsive Design**: Designed with modern dark glassmorphism aesthetics, completely optimized across desktop, tablet, and mobile screens down to 320px.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, React Router 7, Axios, Vanilla CSS.
- **Backend**: Node.js, Express 5, Mongoose.
- **Database**: MongoDB Atlas.
- **Deployment**: Vercel (Frontend) & Render (Backend).

---

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/moulidharanka/booknest.git
cd booknest
```

### 2. Backend Setup
```bash
cd server
npm install
npm run dev
```

### 3. Frontend Setup
```bash
cd ../client
npm install
npm run dev
```
